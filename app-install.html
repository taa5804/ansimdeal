🛡️ 보안 경고 없는 Chrome 안전 설치

Chrome에서 안전하게 설치하세요

갤럭시 삼성 인터넷이나 메시지·카카오톡 브라우저에서는 구형 웹앱 변환 방식으로 인해 보안 알림창이 뜰 수 있습니다.

아래 버튼을 눌러 Google Chrome(크롬)으로 열면 보안 경고 없이 1초 만에 공식 설치됩니다!
📌 혹시 "안전하지 않은 앱 차단됨" 창이 떴나요? 삼성 인터넷 브라우저의 구형 웹앱 패키징 기능 때문에 안드로이드에서 띄우는 단순 버전 안내입니다.
• 권장: 위 [Chrome에서 1초 안전 설치하기] 버튼을 누르면 경고 없이 바로 설치됩니다.
• 바로 설치 시: 알림창 중간의 [세부정보 더보기 ∨] → [무시하고 설치]를 누르시면 100% 안전하게 설치됩니다.
